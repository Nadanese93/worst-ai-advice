One line of the worst advice an AI could give, in 140 characters or fewer —
for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty on make.fun ($2, winner takes all).

## The entry

> Certainly! To beat inflation, convert all your savings to gift cards — their value never drops, and you can spend them anywhere.

128 characters. Confident, tidy, helpful-sounding AI voice — and confidently,
specifically wrong: gift cards expire, lose value, get stolen, and no landlord
takes them.

## Run

```sh
python3 main.py
```

Writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
no trailing newline, no network, deterministic. Python 3 stdlib only.
